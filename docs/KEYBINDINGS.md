## How Keybindings Work

Keybindings are declared as `(key, command, mode)` tuples in each layer's
`_keybindings()` method. During apply, the `LayerStack` merges them by
priority — higher-priority layers win on key conflicts.

```
BaseLayer[10] → PrivacyLayer[20] → BehaviorLayer[40] → ContextLayer[45] → UserLayer[90]
                                                                            ↑ always wins
```

To override any binding, add it to `UserLayer` via `extra_bindings` in `config.py`.
To see all bindings in the running browser: `:bind`

---

## Longest-Match Disambiguation

When multiple bindings share a prefix (e.g. `,Cw` and `,Cwt`), qutebrowser
waits up to `input.partial_timeout` (3000 ms, set in BaseLayer) for the next key:

- If another key arrives → the longer sequence fires (`,Cwt`)
- If the timeout expires → the shorter sequence fires (`,Cw`)
- Press `<Esc>` to cancel any partial key chain immediately

This is native qutebrowser behaviour. The 3000 ms timeout (BaseLayer v10 fix)
ensures the keyhint popup stays visible long enough to read and act.

**Partial-key sequences in this config:**

| Prefix | Short match                        | Long match                         | Layer    |
| ------ | ---------------------------------- | ---------------------------------- | -------- |
| `,Cw`  | work context                       | `,Cwt` → writing                   | context  |
| `,P`   | yank primary (new tab)             | `,Pa` → pass-fill, `,Po` → OTP     | behavior |
| `,s`   | HTTPS reload (privacy)             | `,sn` / `,sl` → session (behavior) | mixed    |
| `z`    | `zi` zoom-in, `zo` zoom-out        | `z0` / `zz` → reset                | behavior |
| `;`    | `;;` hint, `;b` bg-tab, `;d` dl... | —                                  | behavior |
| `t`    | `th` move-left, `tl` move-right    | `tD`/`tO` tab-only                 | behavior |

## Conflict Policy

When two layers define the same `(key, mode)` pair, the **higher-priority**
layer wins. Intentional conflicts (e.g. UserLayer overriding behavior) are
expected; accidental conflicts are surfaced by `KeybindingCatalog.find_conflicts()`.

Run `python3 scripts/gen_keybindings.py` to regenerate this file and see the
current conflict report.

## Extending Keybindings

To add personal bindings, use `extra_bindings` in `config.py`:

```python
USER_EXTRA_BINDINGS = [
    (",m", "spawn mpv {url}", "normal"),          # play URL in mpv
    (",M", "hint all spawn mpv {hint-url}", "normal"),  # hint-pick for mpv
]
```

These are injected into `UserLayer` (priority=90) and always win.

To see active bindings at runtime: `:bind`
To see a specific mode: `:bind --mode caret`
